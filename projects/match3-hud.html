Overview

This concept explores a polished, characterful interface for a mobile match-three game. The decorative frame gives the screen a recognizable theme, while the central board remains the main point of attention.

Interface detail

The HUD artwork develops the same visual language for a themed frame. It shows how decorative elements can support the game’s world while leaving the play area readable.
